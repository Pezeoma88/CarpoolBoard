# CarpoolBoard 

CarpoolBoard is a mobile carpooling app built with React Native and Expo. The app allows users to offer rides, request rides, and reserve available seats.

This project was created for Prototype 1 of my Mobile Development course.

## Features

- Offer a ride
- Add a driver's name and number of available seats
- View available rides
- Reserve a seat with a driver
- Automatically decrease the number of available seats after a reservation
- Display "Ride Full" when no seats are available
- Request a ride
- View users who are looking for a ride
- View the current number of drivers and riders

## Design

CarpoolBoard uses a simple card-based interface to separate available rides from users looking for rides. The app also includes:

- Driver and rider avatars
- Available seat indicators
- Driver and rider summary counters
- Separate "Available Rides" and "Looking for a Ride" sections
- Clear "Offer a Ride" and "Request a Ride" actions

## Prototype 1

Prototype 1 focuses on the basic interaction between drivers and riders. Drivers can offer available seats, users can reserve those seats, and riders can add themselves to the list of people looking for a ride.

Future versions could expand the app with features such as matching riders with drivers, ride destinations, departure times, user profiles, and persistent data storage.
